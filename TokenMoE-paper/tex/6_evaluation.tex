\section{Evaluation Methodology}

The evaluation must answer three questions. First, does metadata-conditioned
prediction outperform global frequency? Second, does it add signal beyond a
bounded temporal history? Third, is any gain robust across model families,
source groups, and prompt segments?

Traces are split by complete source group in time order, using multiple train
fractions. Evaluation is online: a predictor emits a working set, is scored
against the exact vLLM route, and only then observes that request. Main metrics
are expert-label hit rate, exact-token hit rate, and router-score-weighted
coverage at $1\times$, $2\times$, and $4\times$ router top-$k$. Predictor
deltas use paired bootstrap confidence intervals over source groups.

Agent claims require real trajectory prompts and metadata ablations; chat and
instruction corpora can support only prompt-conditioned claims. Unit tests,
synthetic arrays, and external traces without agent metadata validate software
boundaries but not the hypothesis.

Runtime work begins only if \RouteSig consistently exceeds temporal history.
It must then report real expert residency, transfer overlap, latency, throughput,
and prediction-error overhead. Proxy replay is not treated as a systems result.
