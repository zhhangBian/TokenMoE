\section{Implementation}

The Python artifact contains strict dataclass schemas, JSONL readers and
writers, a bounded online \RouteSig store, three explainable predictors, and a
paired group-bootstrap evaluator. Legacy trace versions and non-vLLM backends
are rejected.

The local vLLM fork extends routed-expert capture with an optional score buffer
that follows the same device, host-copy, scheduler-slot, and request-output
indexing as expert IDs. The collector slices prompt tokens, maps native
full-layer or compact-MoE-layer layouts to logical layer IDs, aligns tokenizer
offsets, validates each request, and writes incrementally. Interrupted runs can
resume by validated request ID.

Dataset adapters are separate from the core package. They record source and
conversion provenance and never place raw datasets or generated traces in the
source repository.
