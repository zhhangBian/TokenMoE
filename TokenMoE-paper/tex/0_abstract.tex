Mixture-of-Experts (MoE) serving systems learn a token's expert demand only
when the model router executes, which is late for expert prefetching and
placement. Agent runtimes expose request context earlier, including node role,
execution phase, tool history, and prompt structure. We present \project, a
research design that treats this context as a prior over per-layer expert
working sets while leaving the model router authoritative. \project contributes
a strict admission-request schema, an observational vLLM router-trace path, a
hierarchical route-signature abstraction, and a leakage-resistant online
evaluation protocol. The current artifact establishes this measurement and
evaluation foundation; runtime speedups remain contingent on demonstrating
signal beyond temporal routing history on real agent workloads.
