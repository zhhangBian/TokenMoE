# Research reports

This directory is reserved for reviewed research records: methodology notes,
gate decisions, and concise summaries that remain valid for the current code
and trace schema.

Generated metrics, plots, raw logs, and per-run reports belong under
`$TOKENMOE_ARTIFACT_ROOT`, not in Git. A report added here must identify its
trace manifest, model configuration, source-group split, code revision, and
claim scope. Unverified prototype results are not retained.
